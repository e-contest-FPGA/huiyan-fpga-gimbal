F2 的 Slice / ERAM / DSP 为 19,505 / 96 / 34。V21F1 的资源为 19,096 / 101 / 36。V21F1 相对于其自身起点 V21，Slice 从 21,047 降为 19,096，约减少 **9.27%**。以上来自各自构建归档，正余量适用于已检查路径。外部接口的时序覆盖仍有缺项。

## 屏幕上的 2 帧

`DELAY 002 FRM` 显示基于帧号计算的内部视频帧龄。F2 和 V21F1 的定义是从摄像头帧首到该帧开始输出有效渲染像素，计量单位为采集帧周期。摄像头为 60fps 时，两个帧周期约为 33.3ms。显示面板发光、舵机起转和机械停稳各有独立测量终点。

原参赛报告还记载了 60fps 逐帧分析得到的约 33ms 机械起转估计、5 次重启和 20 分钟观察。本次收到的演示文件为 30fps，且这些试验缺少可关联至明确固件哈希的原始记录，因此作为参赛报告中的历史结果保留。报告各章节记录了不同阶段的方案和参数，包括早期 LED 计时设计。

## 跟踪表现

视频中可以看到绿色手机目标、跟随状态和云台动作。部分帧的绿色框覆盖物体周边，颜色相近的背景仍会影响轮廓。较新的版本加入候选区域筛选和可靠观测门控。浅色背景是台架测试项，现场改善幅度需要用同一物体、距离和光照做前后对照。

本仓库的 `python tools/simulate.py` 运行 8 组独立 HDL 检查，覆盖帧龄、分析流、浅色背景、防抖、跨时钟握手、历史框、曝光和串口。固件与原始工程归档的哈希和文件来源见 [source-provenance.json](source-provenance.json)。
